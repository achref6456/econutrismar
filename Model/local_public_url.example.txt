Une seule ligne : la base du site telle que le téléphone doit l’utiliser (même Wi‑Fi que le PC).

Si sur le PC le blog est à http://localhost:8000/frontoffice/… (racine Apache = dossier View du projet), mettez par exemple :

http://172.20.10.10:8000 

(Vous pouvez aussi terminer par /View : ce suffixe est ignoré pour construire le lien du quiz.)
